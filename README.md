# Viabana Android

Aplicación Android nativa de la heladería Viabana, creada con Kotlin y Jetpack Compose.

## Estado
Versión inicial: pantalla de inicio con categorías Potes, Palitos, Kiosco y Comida para llevar.

## Pendiente
Catálogo, selección de sabores (1 kg: hasta 4; 1/2 kg: hasta 3; 1/4 kg: hasta 2), carrito, Mercado Pago, WhatsApp y administración de pedidos. No se han implementado pagos ni pedidos todavía.

## Desarrollo
Abrir este repositorio en Android Studio con JDK 17 y sincronizar Gradle. Se requiere configurar un entorno Android local para compilar y probar. El proyecto aún no incluye Gradle Wrapper.
